# Archive

Everything below this directory is historical. Nothing here is load-bearing.

These files record how the module reached its current state. They do not describe the current
state. When a file here disagrees with `Monarch.psm1`, the code is right.

Do not cite a file from this directory as evidence for how the module behaves today. Cite the
code, or cite a document under `docs/reference/`, `docs/adr/`, or `CONTEXT.md`.

## What is here

- `phase-01-discovery/` holds the prototype scripts and the step-by-step plans that built the
  Discovery phase, plus the bug-fix plans from the BadBlood work.
- `raw/` holds TODO notes that were later turned into GitHub issues. Several open issues still
  point at these files as their specs.
- Loose plan files that were completed or abandoned.

## Removal

Nothing here is deleted by an agent. Removing this directory is the repository owner's
decision, and it is the last step of the documentation restructure, after every document has
had its decision-relevant content moved into `docs/adr/` or `CONTEXT.md`.
